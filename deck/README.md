# DeFi Loans Workshop deck

Source files of the slide deck published at https://claude.ai/artifact/GekgccCgss7VnFDtVH5Kix
(artifact version 29, saved 2026-11-19).

- `deck.json`: the index (slide order, sections, cover, typeface).
- `slides/<id>.html`: one slide per file, in the deck's order given by `deck.json`. Each `<section>` is a 1920×1080 slide with inline styles; the `<aside>` at the end holds the speaker notes.

Design: the Unlloo website look (Nunito Sans, page #F8FAF7, Deep Forest #1D3814, Olive #697733, Lime #BECD67), per https://www.unlloo.com/ai-design/SKILL.md.

Open placeholders on the last slide: Signal group link or QR, Lightning address.
